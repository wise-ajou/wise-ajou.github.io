Research 연구 분야

고성능 컴퓨팅과 머신러닝데이터 중심 AI 플랫폼클라우드 기반 AI 인프라

고성능 컴퓨팅과 머신러닝

분야 상세 보기

작업의 실행시간과 불확실성을 함께 예측하고, 강화학습 기반 스케줄링과 자동 튜닝으로 HPC 시스템의 성능을 개선합니다.

주요 연구 주제

  • [HPC] 엑사급 초고성능컴퓨터를 위한 오토튜닝 프레임워크 개발
  • Uncertainty-aware runtime prediction
  • Reinforcement learning for job scheduling
  • Large-scale hyperparameter optimization

데이터 중심 AI 플랫폼

분야 상세 보기

대규모 그래프의 GPU 병렬 처리와 분자동역학을 위한 GNN 모델의 실행 성능을 연구합니다. 자율주행 데이터를 저장·질의하는 플랫폼도 개발합니다.

주요 연구 주제

  • [MD-GNN] Multi-GPU 환경에서 GNN 기반의 MLIP 최적화 기법 연구
  • [Big Data] 자율주행 차량의 대용량 주행 시나리오 질의 웹 페이지 개발
  • GPU 기반 그래프 병렬 처리
  • Multi-GPU 환경의 GNN·MLIP 최적화
  • 자율주행 데이터 저장 및 시나리오 질의

클라우드 기반 AI 인프라

분야 상세 보기

LLM 추론의 요청 스케줄링과 KV Cache 활용을 최적화합니다. 다차원 질의를 위한 LSM-Tree 인덱싱과 분산 AI 서비스의 저장·실행 기반을 연구합니다.

주요 연구 주제

  • 다차원 쿼리 처리를 위한 경량 LSM-Tree 인덱싱 기술 개발
  • [LLM Inference] 대규모 언어모델(LLM) 운영을 위한 Inference 최적화 연구
  • LLM 추론 스케줄링과 KV Cache 관리
  • GPU 자원 분할과 모델 서빙
  • 다차원 질의와 LSM-Tree 인덱싱
